# אזורי בחירה — סימולציה על בחירות 2026

סימולציה של שיטת בחירות אזורית-רובנית (חד-נציגית) על תוצאות האמת של הבחירות לכנסת, ברמת קלפי.
המודל הראשי הוא **הכנסת ה-26 (27 באוקטובר 2026)**; בחירות 2022 (הכנסת ה-25) זמינות באתר במתג "בחירות".

**→ [israel-electoral-districts-2022.vercel.app](https://israel-electoral-districts-2022.vercel.app/)** (השם "2022" בכתובת היסטורי)

## מה יוצא (120 מחוזות)

| | גוש השינוי | ימין | ערבי | חרדי |
|---|---|---|---|---|
| **2026, שיטה אזורית** (סימולציה) | 49 | 39 | 20 | 12 |
| 2026, השיטה היחסית (תוצאות אמת) | 48 | 40 | 19 | 13 |

לפי מפלגה זוכה בכל מחוז: הליכוד 53, ישר! 27, הרשימה המשותפת 19, יהדות התורה 12, רע"ם 5, הציונות הדתית–זהות 3, ש"ס 1.
הגושים הם ברירת מחדל שאפשר לערוך באתר; ההגדרות ב-`elections.json`.

## קבצים

| קובץ | תיאור |
|------|--------|
| `elections.json` | **הגדרת הבחירות** — לכל מערכת בחירות: קובץ הקלפיות, אותיות/שמות/צבעי המפלגות, גושי ברירת המחדל. הצנרת וה-UI קוראים רק מכאן. |
| `engine.py` | מנוע החלוקה למחוזות — חלוקה בינארית רקורסיבית (RCB) לכל n, שווי-אוכלוסייה ורציף. `load(eid)` טוען בחירות, `solve(data, n, alpha)` מחזיר שיוך קלפי→מחוז. |
| `build_geojson5.py` | בונה GeoJSON למחוזות (`init(eid)`, `build(n)`). כולל פיצול ערים אורגני (תת-Voronoi קפסיטטיבי) וניקוי רסיסים. |
| `build_maps.py` | מייצר `maps/<בחירות>/n<N>.json` לכל מספר מושבים (120–400 בקפיצות של 5, וגם 215) + `meta.json` + `outline.json`. |
| `blocsim.py` | סימולציית גושים עצמאית (4 או 5 גושים) + מפות PNG; משמשת גם כבדיקה צולבת למספרים. |
| `isr.topo.json` | גבול ישראל (TopoJSON, WGS84). |
| `isr_itm.pkl` | גבול ישראל מומר לרשת ישראל (ITM, EPSG:2039) — משמש לחיתוך המפות. |
| `data/ballots_2026.csv`, `data/ballots_2022.csv` | תוצאות ברמת קלפי, קובצי ועדת הבחירות המרכזית כמות שהם (עמודות מפלגות לפי אות). |
| `data/settlement_coords.csv` | קואורדינטות יישובים (ITM). |
| `index.html` + `maps/` + `outline.json` | המפה האינטראקטיבית (Leaflet): מתג בחירות, סרגל מושבים (120–400), הרכב הכנסת, ועורך גושים. הקבצים נטענים לפי דרישה. |

## הרצה

```bash
python3 engine.py [2026|2022]      # מדפיס הרכב זוכים ל-n שונים
python3 build_maps.py [2026|2022]  # מייצר maps/<בחירות>/ (בלי פרמטר: כל מערכות הבחירות, ~2.5 דקות)
python3 blocsim.py [2026|2022]     # סימולציית גושים + מפות PNG
python3 -m http.server 8793        # צפייה מקומית: http://localhost:8793
```

## הוספת מערכת בחירות

1. להוריד את קובץ הקלפיות של ועדת הבחירות (`https://media<מספר הכנסת>.bechirot.gov.il/files/expb.csv`) אל `data/`.
2. להוסיף ערך ל-`elections.json` (אותיות, שמות, צבעים, גושים; ואם יש בקובץ עמודות שאינן מפלגות — ל-`non_party_columns`).
3. `python3 build_maps.py <id>`.

## שיטה (תקציר)

חלוקה ל-n מחוזות שווי-אוכלוסייה בשיטת חלוקה בינארית רקורסיבית לאורך הציר הראשי. הזוכה בכל מחוז = פלורליות (FPTP). ערים גדולות מפוצלות בין מחוזות; ההצגה סכמטית (תת-Voronoi פרופורציונלי). מעטפות חיצוניות (7.9% ב-2026, 9.6% ב-2022) מוצאות כי אין להן מיקום. פירוט מלא ב-`CLAUDE.md`.

מקור הנתונים: [ועדת הבחירות המרכזית לכנסת ה-26](https://votes26.bechirot.gov.il/).
